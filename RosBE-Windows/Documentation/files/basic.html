Basic Build Commands

build-blastmasteros.cmd
Configures and builds BlastmasterOS on Windows. Run it from the BlastmasterOS Dev Environment repository.
./build-blastmasteros.sh
Configures and builds BlastmasterOS on Unix-like systems. Activate RosBE-Unix and set ROS_ARCH first.
cmake --build BUILD_DIRECTORY --parallel
Builds the configured BlastmasterOS tree.
cmake --build BUILD_DIRECTORY --target bootcd --parallel
Builds the bootable ISO target when that target is available in the configured source tree.
cmake --build BUILD_DIRECTORY --target clean
Removes generated build outputs while retaining the CMake configuration.

The default helper build directory is build/BlastmasterOS under the Dev Environment repository. Set BLASTMASTEROS_SOURCE_DIR or BLASTMASTEROS_BUILD_DIR to use custom locations.

Architecture selection is provided by the active build environment. For RosBE, set ROS_ARCH to a supported architecture.
