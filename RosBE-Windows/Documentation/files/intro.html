Introduction

The BlastmasterOS Dev Environment provides compiler toolchains, build utilities, and shell configuration for building BlastmasterOS.

The operating-system source code is maintained separately in the BlastmasterOS repository. This repository supplies the build environment; it is not a second copy of the operating-system source.

For a standard Windows build, open the development shell and run build-blastmasteros.cmd from this repository. For Unix-like systems, activate RosBE-Unix, set ROS_ARCH, and run ./build-blastmasteros.sh.

The helper scripts call the configure scripts in the BlastmasterOS source tree and use CMake to build it. Use the build help for ISO and clean commands.
