Building BlastmasterOS

The development environment supplies compiler tools and convenience commands. The operating-system source is maintained in the separate BlastmasterOS repository.

Windows

  1. Clone BlastmasterOS beside BlastmasterOS-Dev-Environment, or set BLASTMASTEROS_SOURCE_DIR to the source directory.
  2. Open the BlastmasterOS Dev Environment shell or a supported Visual Studio Developer Command Prompt.
  3. From the Dev Environment repository, run build-blastmasteros.cmd.

Unix-like systems

  1. Clone both repositories and activate RosBE-Unix.
  2. Set ROS_ARCH to a supported architecture.
  3. Run ./build-blastmasteros.sh from the Dev Environment repository.

Build targets

The helper configures the source tree with its own CMake configure script and builds the default target. After configuration, build the bootable ISO with cmake --build BUILD_DIRECTORY --target bootcd --parallel. To clean generated build outputs, use cmake --build BUILD_DIRECTORY --target clean.

Do not assume a successful compile means the OS boots or that an ISO is installable. Test images in a virtual machine using a disposable virtual disk.
